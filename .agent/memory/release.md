# MarioKart64JS (this repo) desktop release (worked for v0.0.1)
- Name is MarioKart64JS (NOT TarioKart64). Release remote = `js` (AgentiLoop/MarioKart64JS); `origin` is the old TarioKart64 repo.
- Electron shell in desktop/: version in desktop/package.json. `npm run game` (Vite build → desktop/game) then `npx electron-builder --mac --win --linux --publish never` (~4 min). Skip AppImage: its helper fails with spawn error -86 (no Rosetta).
- Mac signing is done by electron-builder (identity "Todd Bruss (469UCUB275)", notarize:false). Then notarize manually the same way as GoKart (below), re-zip the stapled .app with ditto over release/MarioKart64JS-X-mac-universal.zip, write SHA256SUMS.txt, and run `gh release create --prerelease`.

# GoKart release procedure (worked for v0.0.2)

- Version lives in 3 places: project.godot `config/version`, export_presets.cfg preset.0 `short_version`/`version` (mac) and preset.1 `file_version`/`product_version` (win, 4-part). Commit "Release X.Y.Z: version bump", `git tag -a vX.Y.Z -m "GoKart X.Y.Z"`.
- Export from a clean worktree (`git worktree add -f /tmp/gk_rel vX.Y.Z`) so another session's uncommitted edits never ship; run `godot --headless --import --path .` first, then `godot --headless --path . --export-release "<preset>" <out>` for presets "macOS" (build/GoKart.app), "Windows" (build/windows/GoKart.exe), "Linux" (build/linux/GoKart.x86_64), "Linux arm64" (build/linux-arm64/GoKart.arm64).
- Mac signing happens inside the Godot export (codesign=3, Developer ID Application: Todd Bruss (469UCUB275), hardened runtime). Notarize yourself: `ditto -c -k --keepParent app zip` → `xcrun notarytool submit zip --keychain-profile "App Store Connect Profile" --wait` (the ONLY stored notarytool profile; "notary"/"AC_NOTARY" don't exist) → `xcrun stapler staple` → verify with `stapler validate` + `spctl -a -t exec`. Re-zip the stapled app with ditto for dist.
- Dist naming: GoKart-X.Y.Z-{macos-universal.zip, windows-x86_64.zip, linux-x86_64.tar.gz, linux-arm64.tar.gz} + SHA256SUMS.txt; `gh release create vX.Y.Z --title "GoKart X.Y.Z" --notes-file ... <assets>` on AgentiLoop/GoKart. Notes format: see /memories/release-notes-preferences.md (emoji headings, Downloads section first).
