# GoKart / Godot quirks

- Godot ignores files whose name starts with `_` (e.g. `tools/_probe.gd` -> "File not found"). Name throwaway probes `tools/probe_x.gd` and delete them before committing.
- Sibling nodes given the same `name` are renamed `@Name@N` at runtime — give per-index names (`"Signal%d" % i`) when tests count them.
- `user_shell` may start in $HOME with AGENT_PROJECT_FOLDER unset: always `cd /Users/toddbruss/Documents/GitHub/GoKart` explicitly.
- Never pipe `./run_tests.sh` through `perl alarm` + grep: the alarm kills zsh but leaves godot orphaned holding the pipe -> the shell call hangs to the 600 s limit. Run `godot --headless --path . -s tests/test_runner.gd > /tmp/log 2>&1 &` under perl alarm and poll the log instead. Whole suite takes ~2-3 min.
- A test file with a parse error makes the runner's `script.new()` fail and `_initialize` abort silently (no RESULT line, hangs until the alarm). Check the log for `Failed to load script` first.
- Another Agent! tab may work in this repo concurrently (menu/HUD restyle, auto-checkpoint commits that sweep ALL working-tree changes). Stage only your own files; check `git status` before committing.
- The title screen (menu.gd `title_shown`) only leaves on Enter (commit 1645c7c; other keys are ignored there): headless checks that go through the menu must send Enter once before their first option key / the Enter that starts the race. The title demo tours the courses every TOUR_HOLD (15 s) after the logo lands (`tour_t` / `veil`); shots taken within 15 s are unaffected.
- Hazard pattern (train / traffic / moles): pure model `scripts/X.gd` (track layout key -> specs, `active()`, `clear_lane` for AI dodging) + Node3D `scripts/Y.gd`, wired in main.gd (`_dodge(driver, hazards, idx)`), `tests/test_X.gd`, `tools/X_check.gd` + `X_shot.gd`.
- Headless tools: `tools/*_check.gd` print PASS/FAIL lines and "<NAME> CHECK: OK"; `_process` runs more than once per physics frame, so one-off checks need a `checked` flag rather than `pf == N`.
- `Control.set_anchors_preset(PRESET_FULL_RECT)` called inside `_ready` (already in a sized parent) keeps the node's current (0,0) rect by adjusting offsets — a SubViewportContainer then renders a 2×2 viewport. Use `set_anchors_and_offsets_preset` there (before add_child either works).
- The `git` tool's commit action stages everything (it swept the other session's `.agent/subagents/*.md` in once) — `git add <my files>` then `git commit` in a shell, or `git rm --cached` + `--amend` right away.
- Another Agent! session's auto-checkpoint commits sweep in any uncommitted file in the repo, including probes — delete throwaway `tools/probe_*.gd` as soon as they are done.
- Shared files (README.md, .agent/autopilot/progress.md) often hold the other session's uncommitted hunks. To commit only your own: `git show HEAD:FILE > /tmp/f`, apply your edits to /tmp/f, `blob=$(git hash-object -w /tmp/f); git update-index --cacheinfo 100644,$blob,FILE` — the index gets your version, the working tree keeps both.
- HUD item window (`hud.gd` `show_item` + `scripts/item_icon.gd`): icons are pure primitive lists from `ItemIcon.glyph(type)` (unit space -1..1); add a `glyph` branch + a `KEY_COLOUR` entry in `tools/item_shot.gd` when adding an item. `item_label.text` keeps "[ NAME xN ]" (block_check / test_battle read it).
- Label3D `outline_size` renders far thinner on screen than a 2D Label's (measured at race distance: 8 px of a 128 px font ≈ 1 blended px, 16 ≈ a crisp rim, 36 = heavy). 3D sign text goes through `UiStyle.style_label3d` (rim = font_size / 8, rounded font) + `board_rim(board colour)`; `tests/test_signs3d.gd` scans scripts/ for hard-coded outline literals > 7 — do not add raw `outline_size = N`.
- HUD results board (`hud.gd`): `show_results(text)` parses the text producers' output (`parse_results` / `split_columns`); checks read `hud.results_text` (there is no results_label any more). Keep the text formats (`"%s %-4s %-8s ..."`, "Press ENTER", all-caps captions) when changing RaceResults / GrandPrix / TimeTrial / Battle text.
- The Agent! `git` tool's commit action stages EVERYTHING (`git add -A`), sweeping the other session's files in. Commit from user_shell instead: stage your files / cacheinfo blobs, then `git commit -F -`. If it happens, `git reset --mixed HEAD~1` and redo the staging.
- Static hazards in rows (snowmen): `Snowmen.clear_lane` plans through ALL rows within LOOK_AHEAD (free spans per row, min |move now| + 1.1 × chained later moves, ties to the middle); AI margin HIT_RADIUS + 1.6 and pair members ≥ 7 m apart, rows ≥ 14 m, or CPU karts get hit (~6 hits / 90 s with margin 1.2 and 6 m pairs; 0 after). Measure with a throwaway launch probe (7 AI karts, 90 s, count `launches`) before committing a layout.
- Logo (`menu.gd` `_build_title`): per-letter Controls on an arch, each a Label stack (shadow, LOGO_DEPTH extrusions, SIGN_RIM rim via `style_sign`, gradient fill with `shaders/logo_gradient.gdshader`). A canvas_item shader on a Label can tint by glyph position via `varying local_y = VERTEX.y` + `texture(TEXTURE, UV).a`; default Label `font_outline_color` is black, so only check it when outline_size > 0. `tests/test_logo.gd` pins the layer stack and the box clearing the banner (162).
- MK64 powerslide (kart_physics.gd): the mini-turbo charge is stick toggles (out past -0.3, back past +0.3), 2 stages (yellow / red), boost only on red; tests / tools drive it with 6-8 frame left / right presses (the player's eased steer needs ~7 frames to swing). Green Hills' start straight is dead straight — a right drift from the centre at 30 m/s hits the right wall in ~40 frames; drift tools place the kart on the left edge (lateral -5) at 16 m/s with the throttle off (drift_check.gd / screenshot.gd).
- Kart nodes in tests: the runner's root is not in the tree during _initialize, so `Kart.new()` + `k._ready()` by hand (wires the model signals), then `k.free()`.
- Course list (`menu.gd` `_refresh_list(names, sel, pictures)`): `list_box` children = one `Row<i>` Control (children `Thumb` = `CourseThumb`, `Name` = Label) per course / arena + the lit bar Panel (no caret); `menu_check` counts `count + 1`. Pictures come from `_track_pictures(mirror)` / `_arena_pictures()` cached in `picture_cache` ("t<i>:<mirror>" / "a<i>"); `ArenaData.make()` returns a RefCounted (do not `free()` it). `tests/test_course_list.gd` pins the row structure.
- The other session may run `git stash` mid-task: uncommitted edits to TRACKED files vanish into its stash (untracked new files stay). Check `git stash list` / `git stash show --stat`, recover with `git checkout stash@{0} -- <my files>` (stages them) and commit at once; their later `stash pop` merges cleanly against identical committed changes. Commit early, don't sit on edits.
- Music (`scripts/music.gd`): songs are step-pattern strings (eighth notes; note / "." hold / "-" rest; drums x s h), all three voices must have the same token count (`Music.valid`), rendered + cached by `Music.stream(key)` (~110 ms a song); keys are TrackLibrary course names plus "battle" / "star". GameAudio: `start_music(key)` then `update_music(delta, started, final_lap, finished, star)` every physics frame; `play_finish(place)`. AudioStreamPlayer.play() outside the tree errors loudly — GameAudio routes every play through `_start()` (is_inside_tree guard) so tests can call `_ready()` / `update_music` on a free node; `.playing` is only meaningful in the headless scene tools.
- `AudioStreamPlayer.playing` works headless (Dummy driver) — scene checks can assert music.playing / volume_db / pitch_scale.
- The other session may leave `scripts/ui_style.gd` parse-broken for minutes (every scene load fails with "Could not preload resource script"); wait and re-run rather than touching it.
- Items "the other way" (MK64 stick down / up + Z): `use_item_alt` action (Q / Backspace) -> `ItemManager.use_item(id, other_way)`; `Items.can_reverse` = single green / red shell (fired back, red non-homing via `make_red_shell(..., homing)`) + banana / fake box (`ItemProjectile.toss`, `in_flight`, `_land`, `owner_grace` 2.5 s). AI: `wants_use` sets `drv.use_alt` (race + battle AI). The key path only fires for a kart with `frozen == false`; `Input.action_press` in a SceneTree tool is seen by the nodes the SAME physics frame (MainLoop runs first), so check results a frame later.
- Headless scene tools: moving kart A off a spot and kart B onto it in the same frame leaves A's physics body there for that step — B gets depenetrated metres sideways. Park targets on fresh spots (throw_check run B) or wait a frame. A kart hit stays immune while spinning: use a fresh target kart per run.
- Course picture (`attract.gd`): `picture` SubViewport shares the demo world via `picture.world_3d = viewport.find_world_3d()` (set in `_init`; `own_world_3d` false) and holds only `picture_cam`; the menu parents `attract.picture_box` into `select_box` at `Menu.PICTURE_RECT`, the minimap `preview` (PREVIEW_AREA 150x96) overlays its corner. `Node3D.global_transform` on a node outside the tree errors and returns identity — read `.transform` in tests. NEVER `git stash` here: it stashes the other session's tracked edits too.
- Menu motion (`menu.gd`): `set_title(on)` sets the flags then `start_motion()` (anim_t = 0) only when `is_inside_tree()` and the change involves the title; otherwise `anim_t = MOTION_DONE` + `_apply_motion()` snaps. Poses are pure (`intro_pose(t)` / `leave_pose(t)`), applied from `_process` while `anim_t < INTRO_TIME + PROMPT_IN` / `LEAVE_TIME`. The test runner's root is NOT in the tree during `_initialize`, so `set_title` always snaps in tests — call `m.start_motion()` and drive `m._process(1/60)` by hand. `select_box.modulate.a` / `position.y` and `title_box.scale / modulate.a` move during a motion: shots must wait ≥ 0.5 s after `dismiss_title()` (menu_shot: 45 frames).
- Roadside scenery (`scripts/scenery.gd` pure + `scripts/scenery_props.gd` MultiMesh node, added by `Track._build_scenery()` as the "Scenery" child when `TrackData.scenery` names a set): `Scenery.SETS[set]` = rules {kind, every, sides, near, far, size, tall?, face, overlap?}; `props(data)` is deterministic (seed = hash(set)) and flips `side` on a mirrored course so Extra is the exact mirror image — draw the RNG before `fits()` so a skipped spot never shifts the rest. New kind = `parts(kind)` list + `RADIUS` entry (+ a rule). Props have no collision; they must stay beyond `WALL` (1.2) + `WALL_GAP` from EVERY road part (`distance_to_center`), which is why big far props fail often inside a loop. `tools/scenery_shot.gd` verifies visually by removing the node and pixel-diffing two frames (colour matching against albedo is useless under the filmic tonemap).
- Slipstream (`scripts/slipstream.gd` pure: `in_wake` strip RANGE 12 m × WIDTH ±1.8 m behind the LEADER's heading, MIN_GAP 1, ALIGN 0.9, MIN_SPEED 12; `leader()` nearest or -1) + `KartPhysics.update_draft(delta, in_wake)` (draft_time → burst `draft_boost_time`, +15 % top speed, signals draft_started / draft_ended; spin_out / stop drop it), wired per frame in main.gd for every kart. A FASTER follower never drafts (it rams the leader and is pushed out of the wake) — checks need the leader ~2 % faster. Green Hills uses TrackData.DEFAULT_PADS (0.2 / 0.45 / 0.7 / 0.9 of 223 samples); after a pad boost ends speed stays > top for ~0.5 s with is_boosting() false. GDScript lambdas capture locals by value: count signals in an Array. To verify the suite while the other session has a parse-broken file: `git worktree add -f /tmp/gk_wt HEAD`, copy your files in, run the runner there.
- Menu audio (`scripts/menu_audio.gd`, owned by menu.gd as `audio`): Music keys "title" / "menu", effects "cursor" / "option" / "confirm"; `set_title(on)` picks the tune, `_process` cross-fades, `leave()` reparents the playing tune + a chime to the scene root (group `menu_audio_out`, `static var leaves`) so Enter's sound survives `change_scene_to_file` — keep the scene change immediate (checks expect the race within 10 frames). `for p in [a, b]:` over typed nodes needs `for p: AudioStreamPlayer in ...` or `var tw := p.create_tween()` fails to infer. Headless probes: a SceneTree `_process` that `return`s on `frames < 5` skips the early stage checks after a `frames = 0` reset.
